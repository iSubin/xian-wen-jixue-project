# 先闻品牌与命名规范

> 状态：正式采用

## 品牌结论

- 母品牌：**先**
- 母品牌英文标识：**XIAN**
- 产品名称：**先闻**
- 产品英文名称：**XianWen**
- 产品定位：**多源知识采集与加工平台**
- 品牌口号：**先闻万象，沉淀为知。**
- 推荐产品入口：`wen.xian.top`
- 推荐仓库及代码标识：`xianwen`

“先闻”是完整产品名称，不再追加“平台”“助手”“知识库”等词作为产品名的一部分。需要说明产品能力时，使用独立的定位副标题。

标准展示形式：

> **先闻**
>
> 多源知识采集与加工平台

## 产品定义

先闻面向个人及团队的知识管理场景，统一接入分散在不同来源中的视频、音频、文章、课程和会议内容，完成采集、转写、清洗、提炼、归档与后续分发，使外部内容转化为可积累、可检索、可继续使用的知识。

对外介绍统一使用：

> 先闻是一个多源知识采集与加工平台，把散落在网络中的内容，变成可以积累和使用的知识。

## 命名层级

产品内部能力采用“先闻 + 功能名称”的方式表达，不为单项能力另外建立品牌：

- **先闻采集**：接入视频、音频、文章、课程和会议等内容来源。
- **先闻转写**：完成音视频转录、字幕提取和文本校正。
- **先闻提炼**：完成摘要、结构化整理与文章生成。
- **先闻知识库**：负责内容归档、检索、关联和持续沉淀。
- **先闻自动化**：负责订阅、Webhook、定时任务和批量采集。

功能名称用于导航、文档章节和能力说明，不取代“先闻”这一产品名称。

## 中文与英文使用规范

- 中文场景优先使用“先闻”。
- 首次面向中英文混合受众时，可写作“先闻（XianWen）”。
- 英文产品名统一写作 `XianWen`。
- 仓库名、包名、命令和其他技术标识统一使用小写 `xianwen`。
- 页面标题推荐使用“先闻｜多源知识采集与加工平台”。
- 品牌口号统一使用“先闻万象，沉淀为知。”

## 域名规范

- 母品牌主域名：`xian.top`
- 先闻推荐入口：`wen.xian.top`

`wen.xian.top` 用于产品官网或 Web 应用入口；文档、API 等服务可在确定部署结构后使用其下级路径或独立子域名，但对外始终以“先闻”为产品主体。

## 文案原则

- 先说明用户获得的结果，再说明转写、模型或 Provider 等实现能力。
- 强调“统一采集、知识加工、持续沉淀”，避免把产品描述为单一下载器或转写工具。
- 产品名和定位副标题分开书写，不把描述性词语拼入产品名称。
- 对外文案保持清晰、克制，不使用无法验证的能力承诺。
