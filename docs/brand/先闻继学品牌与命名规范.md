# 先闻继学品牌与命名规范

> 状态：正式采用

## 品牌结论

- 母品牌：**先**
- 母品牌英文标识：**XIAN**
- 产品名称：**先闻继学**
- 产品英文名称：**XianWen**
- 产品定位：**采集、整理与持续学习的个人文库**
- 品牌口号：**先闻万象，继学不息。**
- 推荐产品入口：`wen.xian.top`
- 推荐仓库及代码标识：`xianwen`

“先闻继学”是完整产品名称。“先闻”是向外采集，“继学”是把材料组织成文库并持续阅读、批注与精进；名字取意于“天行健，君子以自强不息”的昂扬气魄。

标准展示形式：

> **先闻继学**
>
> 采集、整理与持续学习的个人文库

## 产品定义

先闻继学面向个人及团队的知识管理场景，统一接入分散在不同来源中的视频、音频、文章、课程和会议内容，完成采集、转写、清洗、提炼、目录归档、阅读与 Git 交付，使外部材料进入一座可积累、可检索、可在 Obsidian 中继续生长的个人文库。

对外介绍统一使用：

> 先闻继学把散落在网络中的内容采集成篇、依目录成库，让每一次听闻都成为下一次学习的起点。

## 命名层级

产品内部能力采用清晰的两段式表达：

- **先闻 · 采集台**：接入视频、音频、文章、课程和会议，完成转写与提炼。
- **继学 · 文库**：按目录组织文稿，负责阅读、检索、Git 交付和持续沉淀。

技术仓库、Python 包和环境变量继续使用 `xianwen`，不做破坏兼容性的工程改名。

## 中文与英文使用规范

- 中文场景统一使用“先闻继学”。
- 首次面向中英文混合受众时，可写作“先闻继学（XianWen）”。
- 英文产品名统一写作 `XianWen`。
- 仓库名、包名、命令和其他技术标识统一使用小写 `xianwen`。
- 页面标题推荐使用“先闻继学｜采集万象，继学不息”。
- 品牌口号统一使用“先闻万象，继学不息。”

## 域名规范

- 母品牌主域名：`xian.top`
- 先闻继学推荐入口：`wen.xian.top`

`wen.xian.top` 用于产品官网或 Web 应用入口；文档、API 等服务可使用其下级路径或独立子域名，但对外始终以“先闻继学”为产品主体。

## 文案原则

- 先说明用户获得的结果，再说明转写、模型或 Provider 等实现能力。
- 强调“统一采集、知识加工、持续沉淀”，避免把产品描述为单一下载器或转写工具。
- 产品名和定位副标题分开书写，不把描述性词语拼入产品名称。
- 对外文案保持清晰、克制，不使用无法验证的能力承诺。
